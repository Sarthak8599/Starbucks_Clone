# ☕ Starbucks Web Clone

A modern, responsive, and feature-rich front-end clone of the **Starbucks India** web application. Built using HTML5, CSS3, JavaScript (jQuery), and Bootstrap 5, this project reproduces the Starbucks brand aesthetic, interactive ordering flow, digital gifting, and shopping cart experience.

---

## 📌 Project Overview

This project is a comprehensive replication of the Starbucks digital experience. It features handcrafted coffee menus, real-time item searching and category filtering, an interactive cart and checkout system, gift card customization, a corporate gifting portal, store locator, and responsive user accounts.

Designed with clean typography, authentic brand colors (`#1e3932`), and fluid UI micro-interactions, the application delivers an authentic Starbucks customer experience on desktop, tablet, and mobile devices.

---

## ✨ Key Features

- **🏠 Interactive Homepage (`index.html`)**
  - Hero promotional carousel highlighting seasonal specials and new launches.
  - Handcrafted curation categories (Bestsellers, Drinks, Food, Coffee at Home, Ready to Drink).
  - Quick-access banners and rewards highlight cards.

- **☕ Menu & Online Ordering (`order.html`)**
  - Categorized browsing: Drinks, Food, Merchandise, Coffee At Home, and Ready to Drink.
  - Dynamic category switching without full page reloads.
  - Live search bar with instant item filtering and highlighting.
  - Dine-in / Takeaway delivery selector.
  - Veg / Non-Veg dietary indicators and custom modals.

- **🛒 Cart & Order Management (`cart.html`)**
  - Dynamic cart item tracking and real-time total bill calculations.
  - Quantity increment/decrement and item removal controls.
  - Order summary breakdown including taxes and packaging charges.

- **💳 Checkout & Payment Simulation (`payment.html`)**
  - Multi-method checkout supporting UPI, Credit/Debit Cards, Net Banking, and Starbucks Card.
  - Coupon / promo code application interface.

- **🎁 Digital Gift Cards (`gift.html`, `gift-corporate.html`)**
  - Themed cards for different occasions: Anytime, Thank You, Congratulations, and Celebrations.
  - Preview card designs and customize greeting messages.

- **🏢 Corporate Gifting & Hampers (`corporate.html`, `coffee-hampers.html`)**
  - Dedicated portal for bulk orders and business celebrations.
  - Curated gift hamper showcases with custom inquiry workflows.

- **📍 Store Locator (`store.html`)**
  - Discover nearby Starbucks cafes with store timings and amenities.

- **❤️ Wishlist & User Profile (`wishlist.html`, `profile.html`)**
  - User profile dashboard, Starbucks Rewards tier display, and saved wishlist items.

## 🚀 Getting Started

### Prerequisites

All you need is a modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari).

### Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sarthak8599/Starbucks_Clone.git
   ```

2. **Navigate into the project folder:**
   ```bash
   cd Starbucks_Clone
   ```

3. **Open the project:**
   - Double-click `index.html` to open directly in your default browser, or
   - Use the VS Code extension **Live Server** (Right click `index.html` > *Open with Live Server*), or
   - Run a simple local HTTP server:
     ```bash
     # Using Python 3
     python -m http.server 8000
     ```
     Then open [http://localhost:8000](http://localhost:8000) in your browser.
